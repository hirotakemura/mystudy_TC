# Presta For TOEIC

TOEIC L&R（2026年12月19日・目標650点）に向けた、通勤時間中心の学習を管理するスマホ向けPWAアプリです。
ホーム画面に追加でき、オフラインでも動作します。データは端末のブラウザ（localStorage）に保存されます。

> 作成時のプロンプト（仕様）は [docs/TOEIC_APP_PROMPT.md](docs/TOEIC_APP_PROMPT.md) にあります。

> アプリアイコンを画像生成AIで作るためのプロンプトは [docs/ICON_PROMPT.md](docs/ICON_PROMPT.md) にあります。

## 機能

| 画面 | 内容 |
|---|---|
| ホーム | 本番までのカウントダウンと目標点、今の期間（残り日数・今週やること）、**通勤メニュー**（項目ごとに「行き」「帰り」をタップすると分数が学習時間に加算、もう一度で取り消し）、今日の学習時間（内訳を選んで +10/+15/+30分・任意入力）、疲れた日の最低ライン（単語15分）、連続学習日数、今週の合計と週の目標に対する達成率。期間の最終週と本番1週間前（12/12〜）は注意を表示 |
| 演習 | **単語**：TOEIC頻出語188語（600点／730点／860点レベル、例文・和訳つき）をフラッシュカードと4択テストで学習。間隔反復で、正解するたびに次に出す間隔が延び（翌日→3日後→1週間後→2週間後→1か月後）、間違えると最初からやり直し。単語・例文は🔊で読み上げ。<br>**シャドーイング**：Part 1〜4形式の英文18教材（104文）を、通し再生または1文ずつ（自分で言うための間をあける）で読み上げ。速さ0.7〜1.1、英文・和訳の表示切り替え、会話は話者ごとに声の高さを変えて再生 |
| 記録 | 日付を選んで過去の日の学習時間を追加・削除、これまでの記録を内訳別の棒グラフで一覧 |
| ロードマップ | 期間ごとのチェックリスト（今の期間を強調して最初から開く）、通勤メニュー、目安（通勤メニュー×平日日数）と実績の学習時間、単語帳の周回カウンター |
| スコア | L/R別のスコア記録（5〜495の5点刻みで入力チェック）、合計・L・Rの推移グラフ（目標の破線・最新値・タップでツールチップ）と一覧表、3年前のスコアとの差、目標までの残り点数とL/Rどちらを伸ばすかのコメント |
| 振り返り | 週ごとの学習時間（前週比）、日ごとの内訳別棒グラフ、最低ラインだけの日数、今週のスコア、来週の通勤メニュー（本番の週は強調）、振り返りメモと過去のメモ。日曜日は起動時に自動で表示（1日1回） |
| 設定（⚙️） | ダークモード（端末に合わせる／ライト／ダーク）、週の目標時間（既定10時間）、JSONのエクスポート／インポート、旧アプリのTOEICデータの取り込み、データ初期化 |

### 学習時間の数え方

- **演習画面を開いている時間は自動で記録されます**（単語は「単語」、シャドーイングは「リスニング」の内訳）。
  - 操作（タップ・スクロールなど）や音声の再生が3分以上ないと、それ以降は数えません（放置対策）
  - アプリがバックグラウンドの間は数えません
  - 15秒ごとに保存するので、途中でアプリを閉じても計測済みの時間は残ります
- 通勤メニューのチェックは、単語帳・問題集などアプリ以外で学習したときに使います（アプリの演習と二重にならないように）。
- 自動計測・通勤メニューのチェック・手動の記録は、すべて学習時間として合計されます。通勤メニューの内訳（単語・文法など）は項目名から自動で判定します。
- 最低ラインは「達成した」ボタン、または単語の記録が15分以上ある日に自動で達成になります。
- 連続学習日数は、学習時間の記録がある日か最低ラインを達成した日を数えます。今日まだ記録がなくても、昨日まで続いていれば途切れません。

### 旧アプリ（OutSystems学習管理）からの移行

旧アプリの ⚙️ →「TOEICデータを書き出す」で保存したJSONを、このアプリの ⚙️ →「JSONをインポート」で読み込みます（ファイルの種類は自動で判別）。

- 今のデータに**追加**されます。同じファイルを2回読み込んでも重複しません
- 学習時間は「内訳なし」として取り込みます
- 振り返りメモはOutSystemsと共用だったため、「旧アプリのメモ」として自分のメモとは分けて表示します

このアプリ自身のバックアップJSONを読み込んだ場合は、確認のうえ現在のデータを**置き換え**ます。

## 開発

```bash
npm install
npm run dev            # 開発サーバー（http://localhost:5173）
npm run build          # 型チェック + 本番ビルド（dist/）
npm run preview        # ビルド結果の確認（Service Worker もここで動作確認できます）
npm run validate:data  # 計画データ・教材データの整合性チェック
npm run icons          # scripts/gen-icons.mjs の SVG からアイコンPNGを再生成
```

開発サーバーでは `http://localhost:5173/?today=2026-12-14` のように日付を指定すると、その日として表示を確認できます（本番ビルドでは無効）。

技術構成：Vite + React + TypeScript、vite-plugin-pwa（Workbox）。画面遷移はハッシュルーティング（`#/roadmap` など）なので、GitHub Pagesでリロードしても404になりません。

### 読み上げについて

読み上げには端末の音声合成（Web Speech API）を使うので、音声ファイルは不要で、オフラインでも再生できます。声は ⚙️ で選べます。iPhoneでは「設定 → アクセシビリティ → 読み上げコンテンツ → 声」から高品質な英語の声（拡張版）を追加すると聞き取りやすくなります。

## 教材データ（アプリ本体と分離）

| ファイル | 内容 |
|---|---|
| `public/data/vocab/words.json` | 単語（`id`・`word`・`pos`・`meaning`・`example`・`exampleJa`・`level`）。`level` は 1=600点、2=730点、3=860点 |
| `public/data/shadowing/sentences.json` | シャドーイングの教材（`id`・`part`・`level`・`title`・`scene`・`lines`）。`lines` は `en`・`ja` と、会話なら `speaker`（M/W）、応答問題なら Q/A |

単語・英文はこのアプリ用に作成したオリジナルです。追加するときは、既存と重ならない `id` を付けてください（学習状況は `id` で保存されます）。`npm run validate:data` で重複や形式をチェックできます。

## 計画データ（アプリ本体と分離）

ロードマップは `public/data/plan/toeic-roadmap.json` で管理しています。コードを変更せずに期間・通勤メニュー・タスクを修正できます。

| 項目 | 内容 |
|---|---|
| `baseline` | 基準のスコア（3年前の490点） |
| `exam` | 本番の日付・目標点（本番1週間前の注意はこの日付から計算） |
| `minimumLine` | 疲れた日の最低ライン |
| `phases[]` | 期間（`start`〜`end`）、通勤メニュー `commute`、チェックリスト `tasks`、注意 `notes` |

- タスクの `id` はチェック状態の保存キーです（旧アプリと共通）。文言を変えても `id` を変えなければチェックは残ります
- 通勤メニューの内訳は項目名から推定します。明示したい場合は `"category": "vocab"`（`vocab`／`grammar`／`listening`／`part56`／`part7`／`mockReview`）を追加してください
- 修正後は `npm run validate:data` で日付の重なりやidの重複をチェックできます

## デプロイ

### GitHub Pages（GitHub Actionsで自動デプロイ）

1. このリポジトリを GitHub に push する
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. `main` ブランチに push すると `.github/workflows/deploy.yml` が実行され、`https://<ユーザー名>.github.io/<リポジトリ名>/` に公開されます（Actions タブの「Deploy to GitHub Pages」から手動実行も可能）

ワークフローでは、リポジトリ名のサブパスで配信するために `BASE_PATH=/<リポジトリ名>/` を指定してビルドしています。

### Vercel

1. [Vercel](https://vercel.com/) で **Add New → Project** からこのリポジトリをインポート
2. Framework Preset は **Vite**（自動判定）。Build Command `npm run build`、Output Directory `dist` のまま **Deploy**
3. ルート（`/`）で配信されるため `BASE_PATH` の設定は不要です。以降は `main` への push で自動デプロイされます

### ホーム画面に追加

- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「ホーム画面に追加」／「アプリをインストール」

一度開けばオフラインでも動作します。アプリを更新した場合は、次回起動時に自動で新しい版に切り替わります。

## データの保存について

データは端末のブラウザにのみ保存され、サーバーには送信されません。機種変更やブラウザのデータ削除に備えて、⚙️ から定期的にJSONをエクスポートしてください。
